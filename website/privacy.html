Scenic privacy

Scenic stores productions, scenes, and reference images locally on your device. Project content is not sent to Squid Productions or GitHub.

Update checks connect to GitHub to retrieve release metadata and downloads. These requests expose ordinary connection information, such as an IP address, to the hosting provider. You can turn off automatic checks in Scenic → Updates. There is no analytics or advertising code in Scenic or this download page.

The download website is hosted by GitHub Pages. Downloads and bug reports use GitHub, which applies its own privacy policy. Information you choose to post in a public issue is public; do not include private productions.

Project backups are files you choose to save or share. Uninstalling or upgrading the app preserves your locally saved projects.
