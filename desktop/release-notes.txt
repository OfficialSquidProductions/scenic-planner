Scenic 1.4.24

- Windows: File > Import Shot List CSV now opens the file picker from the scene map. Canceling and reimporting retain the existing preview and duplicate-free merge behavior.
- Windows: Undo and Redo tooltips now display Ctrl shortcuts. Apple platform shortcut labels remain unchanged.
- This is a Windows-only binary update. The signed and notarized Mac download and Mac update feed remain at Scenic 1.4.23; no iOS or App Store release is included.
