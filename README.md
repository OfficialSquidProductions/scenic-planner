# Scenic

Free, open-source top-down scene, shot, and lighting planning by Squid Productions. Runs offline on Mac and Windows.

Download from **https://scenic.squidproductions.org/** or [GitHub Releases](https://github.com/OfficialSquidProductions/scenic-planner/releases/latest). Source is licensed under MIT.

## Mac app

Open `release/Scenic.app` from Finder. It runs offline in its own window without a browser, server, account, or runtime installation. The application can be moved into Applications and pinned to the Dock. It supports Apple Silicon and Intel Macs running macOS 13.3 or newer.

Projects autosave atomically to `~/Library/Application Support/Scenic/workspace.json`, with the previous save in `workspace.previous.json`. Pending edits are flushed when closing the window or quitting. Updating the app does not replace project data.

Use File > Open Project, Save Project As, Import Image, and Export Map for native file dialogs. Save Project As exports the existing portable `.scenic` format, so web projects can be transferred into the app. File > Save immediately saves the local workspace.

Build with `python3 tools/build_macos.py` using Xcode command-line tools. The script creates a universal app and a verified disk image in `release/`. The app uses AppKit and WebKit supplied by macOS; it bundles the editor, branding, and Sparkle updater. No commercial font files or user projects are included. Default local builds use ad-hoc signing. Public distribution requires the Developer ID and notarization steps below.

### Developer ID signing and Apple notarization

`tools/notarize_macos.py` copies an existing Mac app into a new Xcode archive and signs every nested executable, framework, helper, and app with an existing Developer ID Application certificate, Hardened Runtime, and secure timestamps. It preserves required entitlements, removes debugger access and inherited Apple-reserved Python identity entitlements, and verifies the complete signature. It never changes the input app or reads/exports private keys. The helper also supports Production Desk's bundled Python runtime and its installer.

Prepare a fresh archive with `python3 tools/notarize_macos.py --app release/Scenic.app --archive release/notarized/Scenic.xcarchive --identity '<Developer ID Application certificate name or SHA-1>' --team '<Apple Developer team ID>'`. Upload through Xcode using `xcodebuild -exportArchive -archivePath <archive> -exportOptionsPlist <options.plist> -exportPath <upload-output> -allowProvisioningUpdates`. The options plist should set `method=developer-id`, `destination=upload`, `signingStyle=manual`, and the same `signingCertificate` and `teamID`. This uses the account already signed into Xcode; no app-specific password or exported API key is needed.

After Apple accepts the upload, use `xcodebuild -exportNotarizedApp -archivePath <archive> -exportPath <output>` to export the stapled app. Verify it with `xcrun stapler validate <app>`, `codesign --verify --deep --strict <app>`, `spctl --assess --type execute --verbose=4 <app>`, and `syspolicy_check distribution <app>`. Gatekeeper must report **Notarized Developer ID**. Package the exported app with `ditto -c -k --sequesterRsrc --keepParent <app> <zip>` so its ticket survives distribution. Notarization applies to the exact signed build: re-signing or rebuilding requires another submission. Publish notarized builds as new versioned archives and switch the feed only after those archives are available; published archive bytes remain immutable. A normal first-open confirmation may still appear on macOS.

For an installer containing another app, notarize and staple the inner app first, then store its ZIP as a sealed installer resource. Extract it into a temporary directory during installation, validate its signature, and copy the app into Applications. Xcode re-signs unpacked nested apps during export, so an unpacked app's earlier ticket may no longer match. A ZIP payload preserves its exact signed bytes and ticket through the outer installer's notarization workflow. Adding a nested ticket after signing the outer bundle invalidates its sealed resources. The signing helper's optional `--preserve-app` only preserves nested apps during its own signing stage; it does not control Xcode's later export.

## Production Desk shot lists

In Production Desk, open **Shot list → Export shots**. In Scenic, choose **Import shot list CSV** under Productions (or **File → Import Shot List CSV**), select the scenes to bring in, and choose **Import selected scenes**. The preview shows new scenes and existing scenes to update. New scene numbers create empty maps in the current production. Reimported scene and shot numbers update their original details while keeping the scene map, camera settings, camera links, and coverage checks. Renaming a scene inside Scenic does not affect matching. The import retains shot descriptions, camera names, lenses, framing, movement, equipment, timing, priority, shooting status, takes, and notes. Export all days and scenes in Production Desk to transfer the complete list; its CSV follows the active filters.

Place a camera, select it, and choose **Link to shot** in Properties. Linking applies a supported lens and shot size while preserving your camera position and notes. Multiple cameras can cover the same shot. Original shot details remain available in Properties and Shot list. Use **Coverage checked** to track your review, and the Shot list totals to find shots without cameras. Omitted shots are excluded from coverage totals. Scenic coverage is independent of Production Desk's shooting status.

Imports, camera links, and checks support Undo, autosave, and portable `.scenic` backups. **Shot list → Export CSV** includes original details, linked camera names, and coverage checks for the current scene. The transfer is file-based; changes in Scenic do not update Production Desk automatically. Reimporting the same scene and shot numbers updates the existing entries without duplicates. New shots start unchecked. Shots absent from the selected CSV remain in Scenic, including their links and checks, so filtered Production Desk exports are safe to merge. Incoming shots follow the CSV order, with retained absent shots afterward. Renumbered scenes or shots import as new entries because the CSV identifies them by number. If multiple existing Scenic scenes have the same imported scene number, choose which one to update in the preview. Run `node tests/shot-list.cjs`, `node tests/shot-reimport.cjs`, and `node tests/shot-editor.cjs` for interchange, selection, reimport, undo, and persistence tests; optionally pass Production Desk's `web/shots.js` path to test its actual exporter with synthetic data.

## Windows app

Download `Scenic-Windows-Setup.exe` from the release page. Windows 10/11 x64 is supported. The installer includes the editor and Electron; no separate runtime, browser, account, or server is needed. Installation is per user. Projects are stored in `%APPDATA%/scenic-planner/workspace.json`, with a previous-save backup, outside the application directory. Upgrading and uninstalling retain these files. Use portable `.scenic` exports to transfer productions between Mac and Windows.

Build on Windows with Node 22 and Python 3.12: `python -m pip install Pillow==11.3.0`, then `python tools/build_windows.py` and `python tools/check_windows.py`. The GitHub workflow runs geometry, catalog, model, and native-storage tests; opens the packaged editor; installs the EXE silently; exercises the installed editor; and verifies reinstall preserves saved data. Test reports and screenshots are workflow artifacts. Release publication follows successful checks.

## Updates and releases

Scenic → Check for Updates checks the official GitHub release channel. Daily automatic checks default on. Automatic downloading/installation defaults off and can be enabled in the Updates submenu. Both platforms require a successful workspace save before installing an update; failed saves block installation and offer retry. Updates replace the app only.

Update prompts show what changed before downloading or installing. Settings → What’s New and Scenic → What’s New reopen the installed release's notes and recent history offline. On Windows, Scenic → View Update Details also reopens notes for an available or downloaded update after choosing Later. Enabling automatic installation keeps the existing unattended behavior.

Maintain release changes in `desktop/changelog.json`, newest first, with the latest version matching `desktop/release.json`. Both build scripts run `tools/release_notes.py` to generate the bundled changelog and `desktop/release-notes.html` / `.txt`. Mac update packaging embeds the HTML in the Sparkle prompt and rejects feeds without notes; Windows packaging embeds the text in `latest.yml` and uses it for new GitHub release descriptions. Missing or mismatched notes block a build. Run `python3 tools/release_notes.py` after editing notes to refresh the buildless browser version. Release 1.4.16 / build 21 adds Apple notarization and selective Production Desk shot-list imports with camera links, coverage checks, and duplicate-free reimport.

Mac uses Sparkle 2.10.0 and Ed25519-signed archives, verified before extraction. Windows uses Electron Updater with HTTPS and SHA-512 validation. Public Mac downloads are Developer ID signed and notarized by Apple, with stapled tickets. Windows builds are not Authenticode signed and may show a SmartScreen prompt.

Release metadata is in `desktop/release.json`. Increase both version and build before publishing a new release. `python3 tools/fetch_sparkle.py` downloads the pinned framework and validates its checksum. Create a publisher key once with Sparkle's `generate_keys --account scenic-planner`; put only the public key in release.json. Never commit or upload the private key. `python3 tools/build_macos.py --update-release` produces the universal app, DMG, signed ZIP, and appcast. `python3 tools/check_macos_updates.py` tests save blocking/retry and verifies archive signatures, tamper rejection, and unrelated-key rejection. Upload the Mac archive before its matching appcast to the same versioned GitHub release as Windows. Published archives are immutable.

The website source is `website/`. The Pages workflow deploys only that directory and the two branding assets. Custom DNS is a CNAME for `scenic` pointing to `officialsquidproductions.github.io`; preserve other DNS records.

## Bug and crash reports

Settings → Report a bug opens an email to alexanderhosier@squidproductions.org. Settings → Crash reports lets you describe an issue, review the diagnostic log, save a copy, and open an email draft to the same address. Nothing is sent automatically.

When the editor process crashes, Scenic reloads the last autosave and offers a report. If the whole app stops unexpectedly, the prompt appears on the next launch. A force quit or power loss can also trigger this prompt. Closing the prompt keeps the latest report available in Settings without repeatedly prompting. Normal quits do not trigger a report.

Reports include the app version, OS, crash/exit details, and recent JavaScript errors, without deliberately including workspace contents. On Mac, a matching macOS crash diagnostic is included when available; system diagnostics can contain file paths and other private details, so review the log before sharing. Mac attaches the report through the system email service. Windows includes the full report in the email body when it fits; longer reports are saved as `Scenic-crash-report.txt` and revealed for manual attachment. If no email app is configured, save the log and email it manually. The browser version can record JavaScript errors, but cannot detect a browser process crash.

## Use

- Pick Camera or Talent and click on the canvas. Open Walls for square, rectangular, circular, and L-shaped rooms; drag a room wall to move the whole room, use its handles to resize or rotate, or enter exact dimensions in Properties. Square and circular rooms keep their proportions by default; disable Keep proportions to stretch them. In room Properties, Break into individual walls separates the outline so each wall can be moved, resized, or deleted independently; Undo restores the room shape. Circular rooms become 64 short segments. Shift-click individual walls on the map or in Scene layers, then use Group selected walls in Properties. You can also start with Select multiple walls in a wall’s Properties. Groups move, resize, and rotate as one shape; Ungroup walls restores independent editing. Open Props for handheld objects, Set for vehicles and room furnishings, or Lights for studio fixtures, practicals, and sunlight. Search from any tab across all four libraries. Drag the panel dividers to widen the library or Properties. Drag the horizontal divider below Scenes up or down to trade scene-list space for item browsing. Drag the handle along the bottom of the top toolbar upward to reduce the scene heading and gain canvas space; the original position is its lower limit. Scenic remembers this height. Double-click the handle or press Home to restore it; arrow keys resize it and Esc cancels a drag. Use the four-pane button beside Scenes to open a separate window with numbered, titled scene previews. Click a preview to switch scenes; the window stays in sync with the active production and scene edits. Settings stays pinned at the bottom; the library uses the space freed by the removed banner. Focused dividers also support arrow keys and Home.
- Use the Productions dropdown to switch between projects, or + to create one. Each production keeps its own scenes. Right-click a scene to delete it. Settings provides appearance controls and Delete project, which removes the current production and all its scenes. Undo restores deletions until Scenic closes.
- Draw walls with two clicks. Select a wall and drag a square endpoint to resize it, or its round handle to rotate it around its midpoint. Doors and windows attached to the wall follow its new position.
- Drag empty map space to box-select walls, props, lights, and other scene items. Use Box select (B) to start over an item. Hold Shift to add to a box selection, or Shift-click to add/remove one item. Drag a selected item to move the whole selection; duplicate, delete, and arrow keys also apply to the selection. Locked images are excluded from box selection.
- Drag objects to move them. Selected furniture, set pieces, props, and reference images show edge/corner handles for resizing and a round handle for rotation. The opposite edge or corner stays fixed while resizing. Hold Shift at a corner to keep proportions or while rotating for 15° steps. Esc cancels a handle drag; Undo/Redo treats the entire drag as one edit. Locked images cannot be transformed. Size, direction, and placement are also editable in Properties. Scene layers is a separate tab beside Properties, so it does not consume property-editing space. Selecting a layer opens that object’s properties.
- Measurements use inches below 12 inches, then feet and inches. Enter sizes as `8 in`, `5 ft 6 in`, `5' 6"`, or a bare number of inches. Grid dots are 1 foot apart, snapping is 1 inch, and the map includes a zoom-aware scale bar. Existing layouts retain their coordinates at three world units per inch. Scale a reference image to a known real-world width in Properties.
- Select a talent marker and drag its forward round handle to show which direction the person faces. The facing triangle turns live while the marker stays in place. Hold Shift for 15° steps; Esc cancels and Undo restores the previous direction.
- Select a camera or a fixture light and drag the round handle in front of it to aim. The coverage cone or light beam updates live. Hold Shift for 15° steps. Sun direction remains controlled by time of day and compass bearings.
- Adjust light intensity, color temperature, beam angle, radius, and direction. RGB sliders replace the light behavior note; moving a channel enables RGB color, and the toggle restores temperature mode without losing the chosen RGB channels. Add one Sun per scene. Enable Use shoot location & date, enter GPS latitude/longitude, shoot date, local time, and the location’s IANA time zone (for example America/New_York), then align true north with the map. The north arrow stays beside Zoom out in the bottom-right controls, and exported maps show it in the bottom-right corner. Scrub the time slider to study changing sun direction. Daylight saving is automatic; repeated local times allow Earlier/Later, and skipped times show a correction message. Sunrise, sunset, bearing, elevation, and polar day/night are shown. Manual daylight hours and bearings remain available when the geographic toggle is off.
- Doors and windows snap to nearby walls and follow wall edits. Door controls set open/closed, hinge side, and opening direction. Uncovered windows transmit light; closed curtains block it.
- Select talent, a camera, or a fixture and Record A. Move it and Record B, C, and more, or place each mark directly on the map. Add action notes and preview the movement along the visible route. Recorded marks stay fixed when the object moves; previews do not change the saved position. Play scene beside Undo/Redo starts all recorded routes together, using each object’s preview duration. Pause/Resume keeps every object on the same clock; Replay restarts the scene.
- Import PNG, JPEG, or WebP images, or drag them onto the canvas. Adjust size, opacity, rotation, and locking. Trace walls over the image to block lighting.
- Set a camera’s lens in millimeters to update its horizontal coverage outline live. Active sensor width defaults to 36 mm (full frame); enter the actual active width for your camera/crop mode. View distance sets the guide plane and reports the width visible there. Walls and closed door leaves stop the guide; open windows transmit it, and closed curtains block it. Fit scene includes the coverage outline. Name cameras, record shot size, and add notes. Camera setups populate the Shot list automatically.
- Add, duplicate, and delete scenes. Undo and redo edits with Command/Ctrl Z and Shift Command/Ctrl Z.
- Scroll to zoom; Space + drag to pan; 0 fits the scene.
- Save project downloads the current production as a portable `.scenic` file including imported images and movement marks. Open project adds it to the Productions list.
- Export map produces a high-resolution PNG; the Shot list can export CSV.

## Storage and lighting

The Mac app saves durable JSON in Application Support. The optional browser version autosaves in IndexedDB in that browser on that device. The hosted and localhost versions have separate browser storage. Download a project backup to transfer work or keep it safe from browser data clearing. No project data is sent to a server. Update checks contact GitHub for metadata and downloads; they can be disabled.

Lighting is an artistic 2D approximation of direct light, with radial falloff, directional sunlight, and hard wall shadows. Geographic Sun mode calculates direction/elevation offline with the [NOAA/Meeus equations](https://gml.noaa.gov/grad/solcalc/calcdetails.html) for dates 1900–2100, while manual Sun mode preserves existing projects. Align the map with true north and select the shoot location’s time zone, which may differ from your computer’s. Sunrise/sunset assume a level horizon and standard refraction; terrain, surrounding buildings, weather, and atmospheric variation can change observed conditions. Sun brightness/color remain artistic. Wall masks are directional 2D occlusion, not height-based shadow lengths or a simulation of vertical window openings. It does not calculate height, bounce light, real fixture photometrics, or calibrated lux. Furniture and talent use scaled planning footprints and do not cast shadows. Camera and light markers are schematic, not physical equipment footprints. Images do not automatically create walls.

## Mapping scale

Scenic uses three internal units per inch consistently for placement, dimensions, snapping, grid, and the scale bar. Props and set artwork fill their entered width/depth after removal of unused icon padding; dimensions describe the top-down envelope, not height. Defaults represent generic items. Measure the actual furniture, equipment, overhangs, costumes, and working space when planning a real location.

Room dimensions and overall wall labels span wall centerlines. Rectangular rooms also accept inside width/depth: each equals the centerline span minus one wall thickness. Exterior size adds one thickness. New walls default to 4.5 inches, an illustrative finished partition (3.5-inch framing plus half-inch panels on both sides), and thickness remains editable. Existing wall thicknesses and saved room dimensions are retained. Circular rooms use 64 straight wall segments; curved dimensions and clearances are approximate. L-shaped and grouped room sizes span their overall centerline envelope, not each individual interior space.

Talent uses an editable ellipse, initially 18 inches front-to-back by 24 inches across the shoulders. This is a planning envelope, not an anthropometric measurement or guaranteed clearance. Legacy markers without dimensions use the same default; locations, facing directions, and recorded marks remain intact. Body and costume sizes vary; [NASA's anthropometry guidance](https://www.nasa.gov/reference/appendix-e-vol-2/) describes the need to account for that variability.

The queen bed default is specifically a 60-by-80-inch mattress ([manufacturer dimensions](https://www.tempurpedic.com/shop-mattresses/all-queen/)); enlarge it for the actual frame. Legacy full apple boxes use the manufacturer's 20-by-12-inch footprint ([Matthews dimensions](https://www.msegrip.com/collections/boxes-bags-blankets-boards/products/full-apple-box)). Other generic catalog dimensions are editable starting points, not verified specifications for every product.

Reference-image pixels carry no physical scale. Enter a known real-world width or height before tracing; Keep proportions is enabled by default to avoid distorting the plan. This assumes an undistorted top-down plan: perspective photographs require correction outside Scenic. PNG exports include a visible scale bar below the title, but pixel size and print scaling are not a fixed architectural print ratio.

Camera guides use the rectilinear relation `horizontal angle = 2 × atan(active sensor width / (2 × focal length))`, with both optical dimensions in millimeters. Width at the guide plane is `distance × sensor width / focal length` ([optics reference](https://www.edmundoptics.com/knowledge-center/application-notes/imaging/understanding-focal-length-and-field-of-view)). New cameras start at 50 mm, a 36 mm active sensor width, and a 10-foot guide distance. Older cameras use their saved lens with those sensor/distance defaults; the legacy independent angle is retained in saved data but no longer controls the outline. The guide is a top-down horizontal approximation: camera tilt, subject heights, furniture occlusion, focus breathing, lens distortion, fisheye, and anamorphic projection are not modeled. Wall clipping uses the same centerline geometry as lighting. Guide distance is adjustable and does not represent a lens's maximum viewing range.
